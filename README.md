# Data Analytics Portfolio

---

## Overview

This repository contains a collection of data analytics projects demonstrating end-to-end analytical workflows, including data extraction, cleaning, transformation, analysis, and visualization.

Each project is designed to solve a specific business problem using structured data analysis techniques.

---

## Core Analytical Skills Demonstrated

Across different projects, the following skills and approaches are applied:

- Data extraction and querying using SQL
- Data cleaning and preprocessing (missing values, duplicates, formatting issues)
- Exploratory data analysis (EDA)
- KPI and metric design
- Data aggregation and transformation
- Insight generation from structured datasets
- Data visualization and storytelling using **either Excel or Tableau (depending on the project)**
- Analytical reporting and documentation

---

## Tools & Technologies

- SQL (data querying, transformation, aggregation)
- Excel or Tableau (EDA, visualization, dashboards)
- Data analysis and business insight development

---

## Project Structure

Each project in this repository follows a consistent structure:

project_name/
│
├── data/ # Raw and processed datasets
├── sql/ # Data cleaning and analysis queries
├── excel/ or tableau/ # Visual analysis (only one used per project)
├── images/ # Screenshots and visual outputs
└── README.md # Project-specific documentation

---

## Individual Projects

Each folder in this repository represents a separate analytics project.

Every project includes its own `README.md` file, which contains:

- Business problem definition
- Data sources and context
- Methodology and analytical approach
- Key insights and findings
- Visualizations and outputs (Excel or Tableau depending on project)
- Project-specific conclusions
